## 🛠️ Usage

Once pdf-master opens, you’ll see a clean window with large buttons. Here’s what each one does:

### 📑 View PDF
- Click **Open** and select any PDF file. Use the scroll bar or arrow keys to flip pages. Zoom in/out with the + and – buttons.

### 🔀 Merge PDFs
- Click **Merge**, then **Add Files** to select two or more PDFs.
- Arrange them in the order you want using the up/down arrows.
- Click **Merge Now** – a new combined PDF appears in the same folder.

### ✂️ Split PDF
- Click **Split**, choose a PDF, and pick the page range (e.g., pages 2–5).
- Hit **Split** – separate PDFs are created for each page or range.

### 🔄 Convert PDF
- Select **Convert** to change a PDF into **Word (.docx)**, **Text (.txt)**, or **Images (.png)**.
- Choose the output format, then click **Convert**. The new file saves next to the original.

### 🔒 Protect PDF (Bonus)
- Use **Protect** to add a password. Enter a password twice, then click **Lock**. To remove a password, use **Unlock** with the correct password.

All actions are instant. You’ll see a green checkmark when done, and the output file is always in the same folder as your original PDF.

## 🧯 Troubleshooting

**“I can’t find the downloaded zip file.”**  
Check your browser’s download bar (bottom or top of the screen). Or press `Ctrl + J` to open the download manager. If it’s not there, search your PC for “pdf-master.zip” using the Start menu search.

**“Windows says the app is blocked.”**  
Click **More info** on the blue warning, then **Run anyway**. This is normal for small indie apps.

**“The app opens but buttons do nothing.”**  
Make sure you’re selecting valid PDF files (not corrupted). Try restarting the app. If the issue persists, close and reopen Windows Explorer, then run pdf-master again.

**“I extracted the zip but there’s no .exe file.”**  
Double-check you extracted the *entire* zip – not just opened it. Right-click → **Extract All** is the correct method. The .exe is inside the folder named “pdf-master”.

**“Can I run this on a Mac?”**  
No – pdf-master is Windows-only. For Mac, you’d need a different tool.

**“The app is slow with large PDFs (100+ pages).”**  
That’s normal. Give it a few seconds. For huge files, close other programs to free up memory.
